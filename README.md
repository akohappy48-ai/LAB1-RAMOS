# Lab 1: Personal Portfolio Website


1. **Website Structure & Design (`index.html` & `style.css`)**
   - Binuo ang layout ng portfolio na may **Hero Section**, **Skills & Tech Stack**, **Featured Projects**, **Interactive Hobbies**, at **Contact Card**.
   - Ginamitan ng **minimalist aesthetic** (malinis na typography, subtle hover effects, at card containers).
   - Fully **responsive** para maayos tingnan sa desktop at mobile.

2. **Interactivity (`script.js`)**
   - Nag-add ng **Light/Dark Mode Toggle** para sa theme switching.
   - May **Dynamic Quote Switcher** para sa random inspirational quotes.
   - Interactive na **Interests / Hobbies section** kung saan nag-iiba ang detalye kapag pinalitan ang napiling interes.

3. **Git & GitHub Version Control**
   - Ginamit ang Git CLI para sa version control (`git add`, `git commit`, at `git push origin main`) para sa bawat pagbabago at update sa code.
